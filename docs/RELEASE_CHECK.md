# Проверка выпуска 1.0

Дата: 28 октября 2026 года. Среда автоматических проверок: Node.js 24.22.1. Браузерная проверка: Chromium, публичный HTTPS-сайт.

## Подтверждено

- 36 автоматических тестов прошли: подпись, SHA-256, состав, JSON/CSV, pin, ограничения, неправильные числа, пути и Unicode, шифрование и независимый CLI.
- Подпись проверена отдельным API Node crypto, шифрование — отдельной реализацией Node AES-GCM/PBKDF2.
- Демо-пакет создан в интерфейсе: 3 файла, 5 критериев, все проверки прошли.
- Fingerprint, совпадающий с ключом, принят; несовпадающий отклонён.
- Некорректный pin и повреждённый новый JSON сбрасывают старый успешный результат; скачивание недоступно.
- Пакет сохранился в IndexedDB после перезагрузки и повторно открылся с проверкой.
- Зашифрованный экспорт скачан и импортирован обратно. Неправильный пароль отклонён, правильный позволил проверить пакет.
- Однофайловый проверяющий, открытый по HTTPS, независимо расшифровал тот же файл и подтвердил подпись, pin и 5 критериев.
- Визуально проверена настольная версия.

## Пределы проверки

Не проверялись Safari, Firefox, мобильные браузеры, режим file://, восстановление полного программного стека, внешние интеграции и 24/7-доступность. Автономный проверяющий содержит весь код внутри HTML и не делает сетевых запросов, но локальные политики браузеров могут ограничить WebCrypto в file://. В таком случае применяйте localhost или CLI.

Локальный предпросмотр среды недоступен (preview relay unavailable); проверка интерфейса проведена на опубликованной версии. Аудит был внутренним, не внешним. Продукт не содержит финансовой торговли, рынка активов, удостоверения личности и юридического оформления прав.
